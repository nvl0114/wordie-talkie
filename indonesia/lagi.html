INDONESIAN • LAGI

⏳ 印尼語的「lagi」

印尼文的 lagi 有幾種常見的意思，可以表示中文的 「正在、在」 或 「再」。 具體意思要根據句子的情況來判斷。

每個例句都有 🔊 可以聽發音，排字遊戲也可以一邊點單字一邊聽 😊

CAROUSEL 1

▶️ lagi + 動詞

當 lagi + 動詞 時，可以表示中文的 「正在」，用來表示某個動作正在進行。

句型：S + lagi + Verb + Object

例句

💡 Makan = 吃
Pergi = 去／出去／出門

🚫 「lagi」的否定句

「lagi」的否定形式是在後面加上 gak， 表示中文的 「不／沒」。

句型：S + lagi + gak + Verb + Object

📍 lagi di + 地點

如果要表示人現在所在的地方，可以使用 lagi di + 地點， 相當於中文的 「在 + 地點」。

句型：S + lagi di + 地點
